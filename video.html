OFFICIAL LIVE QUERY

电视内容检索与视觉分析

GDELT API

直接调用 GDELT 官方 TV 2.0 / TVAI：字幕关键词、频道趋势、ASR、屏幕 OCR 和视觉概念。查询结果在官方 API 页面打开。

TVAI 查询示例：visual:"POLICE"、ocr:"GAS PRICES"、asr:"climate"。官方接口会按其数据范围和延迟返回结果。

加载视频后导入 SRT/VTT，字幕会按时间码显示并可点击跳转。

使用方法：① 选择本地视频，或填入允许跨域的公开视频 URL；② 选择对应的 SRT/VTT 字幕；③ 在字幕列表点击时间码回放、输入关键词检索，必要时导出截帧和证据 JSON。统计只基于当前视频、字幕和本页操作记录；ASR/OCR 需要明确接入模型或受控后端，页面不会伪造识别结果。

SOURCE BOUNDARIES

数据边界与来源说明

TV-GKG 提供电视新闻的字幕、主题、情绪和时间码等结构化信号，但不是 GDELT 托管的全球视频档案。ASR 与屏幕 OCR 属于本台可扩展的视频处理层；结果必须标注机器生成、来源地址和 UTC 时间码，并与原始视频人工比对。
