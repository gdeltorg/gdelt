DATA BOUNDARY / 数据边界

与 GDELT 的关系

本站 GDELT 层
Events、GKG、Mentions、DOC 和电视视频页面继续使用本站快照与云端 GitHub Actions 生成的数据。

外部 World Monitor 层
实时地图、船舶、航空、市场、基础设施和网络信号由 worldmonitor.app 提供，更新时间和口径以其页面为准。

核查建议
同一事件可先在 World Monitor 查看实时态势，再回到本站通过事件、知识图谱、提及和视频页面核对媒体证据。
