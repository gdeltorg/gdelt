不止三大库

GDELT 是一套全球新闻、事件、知识图谱、地理、图像、电视和情绪分析基础设施。首页只放入口；本页区分实时数据、实时 API、延迟数据和衍生能力。

01 · LIVE DATASETS

Events · GKG · Mentions

三大实时数据流：事件行为与参与者、知识图谱实体与主题、同一事件在新闻中的传播提及。当前站点保存快照、行数、时间点和原始文件。

02 · DOCUMENT SEARCH

DOC 全文检索

按关键词、来源、语言、国家、时间、图片和媒体语气检索文章，支持文章列表、媒体量时间线和 tone 时间线。

官方实时 API

03 · GEOGRAPHY

GEO 地理与地图

从新闻中的国家、城市、行政区和地点构建地理热度、来源国对比与 GeoJSON 地图。地图表示媒体提及，不必然等于事件发生地。

官方实时 API
打开 GEO API ↗

04 · VISUAL NARRATIVES

VGKG 图片与视觉

处理图片中的对象、活动、OCR、Logo、人脸、面部语气、SafeSearch、颜色与视觉地理。适合作为图片线索和视觉专题，不替代人工核验。

可扩展模块

05 · BROADCAST + VIDEO

TV-GKG 电视与视频

GDELT 已分析的美国电视新闻字幕数据：主题、情绪、地理、来源和时间码，并可回放 Internet Archive 片段。本站已接入官方 TV-GKG 快照统计；本地视频工作台另用于授权视频的字幕、截帧和证据整理。

TV-GKG 统计已接入 · 有延迟

GCAM · Tone · Network

从 GKG 的主题、实体、引用、AllNames、数量和 GCAM 维度构建语气、情绪、叙事、实体关系和来源网络。网络图与综合评分属于本台衍生视图。

跨语言新闻

GDELT Translingual 将多语言新闻纳入统一的事件和知识图谱处理，适合做跨语言主题、国家和来源比较；机器翻译应标注为机器处理结果。

历史档案与时间回放

GDELT 1.0 提供更长历史跨度；本台从首次成功运行开始保存 2.1 快照。可做周期对比、事件密度回放和趋势复盘，但快照累计不是跨期唯一记录数。

IMPORTANT DISTINCTIONS

数据边界

Events、GKG、Mentions、VGKG 和 GDELT 1.0 是数据集；DOC 和 GEO 主要是实时查询 API；TV-GKG 是有延迟的电视字幕数据；ASR、屏幕 OCR、关键帧和说话人识别属于可扩展的视频处理层。文章正文、出版商图片、广播视频和音频不应被描述为 GDELT 托管的完整归档。
